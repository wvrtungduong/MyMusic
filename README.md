# MyMusic

A simple desktop application developed using **Windows Presentation Foundation (WPF)** as part of the PRN212 course assignment at FPT University. This project is a basic MP3 music player that uses the local file system to manage and play audio files. It was created purely to practice WPF application development, file I/O, and event-driven programming in C#.

## Technologies Used

- C#, ASP.NET Core
- Windows Presentation Foundation (WPF)

## Features

- Load MP3 files from the local windows device
- Basic playback controls:
  - Play and pause audio
  - Skip to the next or previous track
- Display the current playlist
- Simple desktop interface
